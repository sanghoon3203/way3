# 챕터 강남권 - 구조 변경 설명

## 변경 날짜
2025-10-15

## 변경 이유
서예나의 스토리가 메인 스토리에서 직접 퀘스트를 제시하는 방식에서, 더 자연스럽게 서예나와의 대화로 유도한 후 DIALOGUE 탭을 통해 서브 퀘스트를 진행하는 구조로 변경

## 주요 변경사항

### 1. Act 2 메인 스토리 변경 (노드 /002~/020)

**변경 전:**
- /019: 서예나가 직접 "5대 명소를 방문하세요" 제안
- /020~023: 퀘스트 상세 설명 및 시스템 메시지
- 메인 스토리에 퀘스트가 직접 포함됨

**변경 후:**
- /019: 서예나가 "기회를 주겠다, 하지만 더 이야기를 나눠야겠다"
- /020: "로데오 아레나 안으로 들어오세요" + 대화 시작 암시
- 메인 스토리 일시 중단 시스템 메시지 추가
  - "다음 진행을 위해 서예나와 대화가 필요합니다"
  - "MerchantDetailView → DIALOGUE 탭에서 계속"

### 2. 서브 퀘스트 분리 (노드 /021~/050)

**새로운 섹션 생성:**
```markdown
## 📖 서브 퀘스트: 서예나와의 대화 (DIALOGUE 탭 콘텐츠)
```

**퀘스트 발동 위치 변경:**
- 변경 전: 메인 스토리 중간 (/020)
- 변경 후: 서브 퀘스트 섹션 시작 부분

**노드 재구성:**
- /021: 로데오 아레나 내부 첫 입장
- /022: 서예나의 사무실
- /023: 진짜 시험 제안 ("강남권 5대 명소 방문")
- /024~026: 퀘스트 상세 설명 (5대 명소 리스트, 증표, 제한시간)
- /027~050: 5대 명소 순례 과정 (24개 노드)
  - /027~029: 강남역 언더그라운드 마켓
  - /030~032: 코엑스 크리스탈 팰리스
  - /033~035: 청담동 명품 거리
  - /036~038: 가로수길 트렌드의 거리
  - /039~046: 압구정 로데오 (최종 확인 및 인정)
  - /047~050: 서예나의 제안, 조언, 작별

## 게임 플레이 흐름

### 변경 전
```
메인 스토리 /002~012 (서예나에 대해 듣기)
→ 메인 스토리 /013~019 (서예나 만남)
→ 메인 스토리 /020~023 (퀘스트 받기)

```

### 변경 후
```
메인 스토리 /002~012 (서예나에 대해 듣기)
→ 메인 스토리 /013~020 (서예나 만남 + 대화 제안)
→ [메인 스토리 일시 중단]
→ MerchantDetailView 접근
→ DIALOGUE 탭 클릭
→ 서브 퀘스트 /021~050 (서예나와 대화 + 5대 명소 순례)
→ [서브 퀘스트 완료 → 메인 스토리 복귀]
→ Act 3 시작 (/051~)
```
