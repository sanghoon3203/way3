## 스토리 핵심 설계

### 황금탑의 5개 층

강남권의 중심에 나타난 **"황금탑"**은 탐욕의 결정체.
이 탑의 꼭대기에 도달해야 강남권의 균형을 되찾을 수 있다.

**5개 층의 시련:**
- **1층 - 탐욕의 환영**: 익명의 가면 없이는 환영에 잡아먹힘 → **로데오 가면 필요**
- **2층 - 독기의 정원**: 마법의 독가스가 가득, 해독 없이는 사망 → **라부지에 포션 필요**
- **3층 - 꿈의 미로**: 가짜 꿈과 진짜 출구를 구별 불가 → **원더랜드 지팡이 필요**
- **4층 - 정보의 암호**: 고대 암호문 해독, 집중력 없이는 불가능 → **테라하우스 원두 필요**
- **5층 - 수호자의 시험**: 탐욕의 수호자와 전투 → **일륜도 필요**

**각 Personal Item은 서브퀘스트 완료 후에만 획득 가능**

## 스토리 구조 요약

### 진행 흐름

```
황금탑 출현 →

1층 봉쇄 (가면 필요) →
서예나 찾기 → 친밀도 부족 → 서브퀘스트 완료 → 로데오 가면 획득 →
1층 돌파 →

2층 봉쇄 (포션 필요) →
앨리스 찾기 → 친밀도 부족 → 서브퀘스트 완료 → 라부지에 포션 획득 →
2층 돌파 →

3층 봉쇄 (지팡이 필요) →
애니박 찾기 → 친밀도 부족 → 서브퀘스트 완료 → 원더랜드 지팡이 획득 →
3층 돌파 →

4층 봉쇄 (원두 필요) →
진백호 찾기 → 친밀도 부족 → 서브퀘스트 완료 → 테라하우스 원두 획득 →
4층 돌파 →

5층 봉쇄 (검 필요) →
주블수 찾기 → 친밀도 부족 → 서브퀘스트 완료 → 일륜도 획득 →
5층 돌파 →

5개 아이템 합체 → 강남의 증표 획득 → 챕터 완료
```

### Personal Item 필수성

각 Personal Item은 **스토리 진행의 절대적 필수 요소**:

1. **로데오 가면**: 탐욕의 환영 통과 (없으면 1층 진입 불가)
2. **라부지에 포션**: 독가스 해독 (없으면 2층 진입 불가)
3. **원더랜드 지팡이**: 진실 구별 (없으면 3층 진입 불가)
4. **테라하우스 원두**: 암호 해독 (없으면 4층 진입 불가)
5. **일륜도**: 수호자 전투 (없으면 5층 진입 불가)

### 서브퀘스트 필수성

모든 Personal Item은 **서브퀘스트 완료 없이는 획득 불가**:
- 친밀도 0 → 거래 불가
- 서브퀘스트 완료 → 친밀도 30
- 친밀도 30 → 거래 가능 → Personal Item 획득
